- The new power: the page can run named `aos workspace` verbs that create a workspace, write allow-listed `workspace.md` frontmatter, record an alias or a hidden path, make one model call for a draft, and move workspace folders between `workspaces/` and `workspaces/_archive/` with their caches. They write only under `workspaces/**` and `brain/_index/**` (maps, threads, the hidden list, `BRAIN.md` through `build-brain-md`), plus one named exception: the `status/` tag line of the project notes D27 links by `workspace:` or exact slug in `brain/memory/projects/`, only when the file exists and is not a symlink. Nothing is deleted and the runtime's folders never move. Resume and Clone are typed into a visible terminal, the accepted shell risk (SECURITY.md:72).
- Argument kinds (`surfaces.ts`; none may start with `-`; PR 1 adds `WS` and `REL`): `WS` `/[^\s._\/\\-][^\/\\\0\n\r]{0,127}/` (an existing name: not `.`, `..`, `_x`, nor containing `\`); `KEBAB` `/[a-z0-9](?:[a-z0-9-]{0,62}[a-z0-9])?/` (a new name); `REL` `/(?!\/)(?!(?:.*\/)?\.\.(?:\/|$))[^\0\n]+/` (`--file`); `HASH` `/none|[0-9a-f]{16,64}/` (`--expect`); `PATH` `/(?:\/|~\/)[^\0\n\r]+/` (adopt, hide).
- Surface rules (all on `cli/aos.js`; flag order fixed, the combinations generated as data like the shell list at `surfaces.ts:142`): `workspace draft WS --json`; `workspace set WS --set JSON_OBJ --expect HASH [--dry-run] --json`; `workspace archive|restore WS --json`; `workspace rename WS KEBAB --json`; `workspace new KEBAB [--git] [--pin] [--empty] --json`; `workspace adopt PATH --into WS --json` (alias only; the page never gets the move form); `workspace hide|unhide PATH --json`. No `stubs` rule: only a terminal types it. The `source` cites `views/spaces/*`, `ui/spaces/{DraftModal,NewSpaceModal}.ts` and `data/terminalLauncher.ts` (`createAndLaunch`, `linkRepo`); a comment records the live check's date, as `:268-269` does for Sessions.
- Validation in the runtime, never only in the regex:
  - An existing name passes `WS` and its realpath is a direct child of `workspaces/` (or `_archive/` for restore); `--into` is such a name.
  - A new name is not `RESERVED` or `scratch`, does not exist and is not held by an archived workspace; `rename`'s must already be kebab-case, while `new` keeps slugifying for terminal use (the page's `KEBAB` rule means the name it confirmed is the one made).
  - A path (`adopt <path>`, `hide|unhide <path>`) is absolute or `~/`, normalized, outside the vault, not `/` or home, and neither inside nor containing `hostDirs('claude').configDir` or `hostDirs('codex').configDir`; adopt's and hide's must equal the cwd of a current outside row (vanished included) in the snapshot or `session-index.json`, unhide's a stored entry.
  - `set` keys and types: `status` one of active, paused, done or empty (clears it); `pinned` a JSON boolean; `objectives` ≤ 20 strings of ≤ 200 characters; `summary`, `next` ≤ 500; `repo` checked like `repoPath`, an existing directory, not `/`, home, or inside or containing a host config folder; every value refuses `[\u0000-\u001f\u007f\u2028\u2029]`.
  - `--expect` compares the file's hash; writes are atomic (`fsx.writeAtomic` replaces a symlinked `workspace.md` rather than following it, and `set` refuses to read through one). Stubs open with `'wx'` (a dangling link counts as existing); files are read only when `lstat` says regular and the realpath is inside the workspace.
- Refusals: archive, rename and restore refuse `RESERVED` names and `scratch`; a workspace named by a `persona/teams/*/running/` marker; one with an app thread whose last `prompt` has no `done` and was written in the last 30 minutes; a repo whose `.git/worktrees/` is not empty (naming them and pointing to `git worktree repair`); restore onto an existing `workspaces/<n>`; any moving verb under `AOS_HEADLESS=1` (precedent `cli/config-cmd.js:115-118`).
- Confirmation: Archive, Restore, Rename and Adopt open a `ConfirmModal` naming the source and destination (or the alias), the threads that move and the notes whose tag flips; Cancel spawns nothing.
- No new IPC: no channel, preload function or zod schema. Verbs run through `runAosJson` → `proc:spawn` → `WritePolicy.canSpawn` and `programRefusal`/`cwdRefusal` (cwd is the vault); the Draft's 120 s timeout lives in the page (`aosRun.ts:52`); `sandbox.spec.ts`'s bridge-shape check is unchanged. A deep link only selects (D12).
