# graphify as part of the brain — plan

Date: 2026-09-23 · Spec: `docs/superpowers/specs/2026-09-23-graphify-design.md`

## Goal

Every AgenticOS install ships a knowledge graph of its vault. graphify is installed and pinned by
`aos init`. Two background passes keep the graph current: a free structural one and a capped semantic
one. Claude and Codex query it through `graph_*` tools on the existing `agenticos` MCP server.

## Interview decisions (2026-09-23)

| Topic | Decision |
|---|---|
| Install | Required and on by default. `uv` is a hard `aos init` prerequisite. `aos graph off` stops rebuilds. |
| Semantic pass | Runs in the background too, not only on request: at most daily, incremental, and on its own `graph:` budget (`graph.semantic.perDayUsd`) rather than the $0.50 hook cap (spec D10). |
| Semantic backend (after the spike) | `claude-cli` through an AgenticOS shim (lean headless flags, no thinking, per-call and per-day caps, ledgered per call). Ollama is deferred (spec D6, D11). |
| Next step | Plan and spike first, then stop for review before PR 1 code. |
| Semantic gate (D11) | `"auto"`: off under an explicit `ollama` or `none` provider; `aos graph semantic on\|off` overrides. |
| Thinking (D12) | Folded in: `MAX_THINKING_TOKENS=0` for every effort-less `claude -p` call (hooks + shim); the reasoner keeps its effort dial. |
